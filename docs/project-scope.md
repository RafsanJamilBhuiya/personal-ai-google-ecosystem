# Project Scope Register

## In Scope

1. Repository and deployment foundation
2. GitHub Pages frontend
3. Cloudflare Workers backend/API layer
4. Google OAuth and Google API integration
5. Google Sheets database architecture
6. Google service integrations
7. Multi-provider AI routing and fallback
8. AI agent, command, tool, planning, and execution architecture
9. Chat, manual control, dashboard, tasks, settings, and logs
10. Real-time task/status synchronization
11. Security, validation, testing, CI/CD, deployment, and production validation

## Out of Scope

- Public multi-user SaaS
- Subscription/billing system
- Public API marketplace
- Enterprise tenant management
- Unnecessary microservice/Kubernetes complexity

## Status Convention

- **Blueprint:** designed/documented but not implemented
- **Structure:** repository location created, implementation pending
- **Implemented:** code/integration exists
- **Validated:** implementation has passed the relevant checks
- **Production-ready:** implementation, security, deployment, and validation criteria are satisfied
